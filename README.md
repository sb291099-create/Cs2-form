# Форма команд CS2

Дашборд текущей формы команд CS2 и прогноз матчей по картам: данные Liquipedia, рейтинг и новости HLTV, сводки Claude. Всё работает в облаке: ничего не нужно ставить на компьютер.

## Как это устроено

- **Сбор** (`cs2form/liquipedia.py`, `cs2form/update.py`): каждые 6 часов GitHub Actions через официальный API Liquipedia скачивает турниры тиров S/A/B за 180 дней: каждую карту со счётом по раундам, ближайшие матчи, составы команд на каждом турнире и ссылки на интервью. С HLTV берутся рейтинг команд и лента новостей.
- **Модель** (`cs2form/model.py`): логистическая регрессия на признаках «до матча» — общий Elo, Elo на конкретной карте, форма текущего состава (матчи до смены состава не учитываются), опыт на карте, свежая смена состава, посев. Проверка на истории: учим на первых 60% карт по времени, проверяем на остальных (вкладка «Модель»).
- **Вето и матч**: жадная симуляция вето (команды выбивают карты, которые не играют, и самые невыгодные, выбирают самые выгодные), шанс серии считается по картам, которые реально будут сыграны.
- **Новости** (`cs2form/news.py`): для матчей на 3 дня вперёд — новости HLTV и интервью по обеим командам и заметки о составах; при наличии секрета `ANTHROPIC_API_KEY` Claude пишет сводку и ставит флаги риска.
- **Дашборд** (`app.py`, Streamlit): «Матчи дня», рейтинг формы, команда, сравнение, «Модель».

## Запуск

1. **Сбор данных:** вкладка **Actions** → «Обновить данные» → **Run workflow**. Дальше он запускается сам каждые 6 часов.
2. **Дашборд:** зайти на [share.streamlit.io](https://share.streamlit.io) через GitHub → **Create app** → репозиторий `Cs2-form`, ветка `main`, файл `app.py` → **Deploy**. Получится постоянная ссылка; после каждого обновления данных дашборд подтягивает их сам.

## Ограничения

- Статистика и страницы матчей HLTV закрыты Cloudflare от серверов GitHub, поэтому карты берутся с Liquipedia (по правилам их API: свой User-Agent, не чаще запроса в 2 секунды).
- Порядок вето на Liquipedia обычно не записан, поэтому вето предсказывается по карт-пулам, а не учится на реальных вето.
- Модель угадывает около 60% карт — это честный уровень для CS2; используйте её как ориентир, а не как гарантию.
