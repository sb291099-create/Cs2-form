# Форма команд CS2

Дашборд текущей формы команд CS2 на данных HLTV. Всё работает в облаке: ничего не нужно ставить на компьютер.

## Как это устроено

- **Сбор данных** (`cs2form/scraper.py`, `cs2form/update.py`): раз в день GitHub Actions скачивает с HLTV результаты всех карт команд топ-50 за последние 180 дней и рейтинг HLTV, и сохраняет их в `data/maps.csv` и `data/ranking.csv`.
- **Метрики** (`cs2form/metrics.py`):
  - **Elo** по всем картам с учётом силы соперника и разницы раундов, плюс отдельный Elo на каждой карте.
  - **Форма**: насколько команда за 90 дней выигрывает чаще или реже, чем предсказывал её рейтинг. Свежие карты весят больше (полураспад 30 дней).
  - Винрейт, разница раундов, серия, последние 5 карт, карт-пул.
  - **Прогноз матча**: шанс на каждой карте, на одну карту в среднем и в bo3, справедливые коэффициенты.
- **Дашборд** (`app.py`, Streamlit): рейтинг формы, страница команды, сравнение двух команд.

## Запуск

1. **Сбор данных:** вкладка **Actions** → «Обновить данные HLTV» → **Run workflow**. Дальше он запускается сам каждый день в 08:00 МСК.
2. **Дашборд:** зайти на [share.streamlit.io](https://share.streamlit.io) через GitHub → **Create app** → репозиторий `Cs2-form`, ветка `main`, файл `app.py` → **Deploy**. Получится постоянная ссылка; после каждого обновления данных дашборд подтягивает их сам.

## Ограничения

- У HLTV нет официального API, сайт закрыт Cloudflare и в правилах запрещает автоматический сбор. Сборщик ходит медленно (запрос раз в 2.5–5 секунд), но HLTV может блокировать серверы GitHub. Если так случится, запуск упадёт с понятной ошибкой, и нужно будет менять источник (например, на PandaScore или GRID).
- Если HLTV поменяет вёрстку, парсер нужно будет поправить; тесты лежат в `tests/`.
