# Форма команд CS2

Дашборд текущей формы команд CS2: результаты из PandaScore, рейтинг из HLTV. Всё работает в облаке: ничего не нужно ставить на компьютер.

## Как это устроено

- **Сбор данных** (`cs2form/pandascore.py`, `cs2form/update.py`): раз в день GitHub Actions скачивает из API PandaScore результаты всех карт турниров тиров S/A/B за последние 180 дней (токен лежит в секрете `PANDASCORE_TOKEN`), а с HLTV только рейтинг команд (`cs2form/scraper.py`). Всё сохраняется в `data/maps.csv` и `data/ranking.csv`.
- **Метрики** (`cs2form/metrics.py`):
  - **Elo** по всем картам с учётом силы соперника и разницы раундов, плюс отдельный Elo на каждой карте.
  - **Форма**: насколько команда за 90 дней выигрывает чаще или реже, чем предсказывал её рейтинг. Свежие карты весят больше (полураспад 30 дней).
  - Винрейт, разница раундов, серия, последние 5 карт, карт-пул.
  - **Прогноз матча**: шанс на каждой карте, на одну карту в среднем и в bo3, справедливые коэффициенты.
- **Дашборд** (`app.py`, Streamlit): рейтинг формы, страница команды, сравнение двух команд.

## Запуск

1. **Сбор данных:** вкладка **Actions** → «Обновить данные» → **Run workflow**. Дальше он запускается сам каждый день в 08:00 МСК.
2. **Дашборд:** зайти на [share.streamlit.io](https://share.streamlit.io) через GitHub → **Create app** → репозиторий `Cs2-form`, ветка `main`, файл `app.py` → **Deploy**. Получится постоянная ссылка; после каждого обновления данных дашборд подтягивает их сам.

## Ограничения

- Статистика карт HLTV закрыта Cloudflare от серверов GitHub, поэтому результаты берутся из PandaScore. На бесплатном тарифе там может не быть счёта по раундам и названий карт: тогда дашборд прячет колонку «Раунды ±», карт-пул и шансы по картам и считает всё по общему Elo.
- Если рейтинг HLTV не скачается, дашборд работает без колонки «HLTV #».
