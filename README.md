# Форма команд CS2

Дашборд текущей формы команд CS2, прогноз матчей по картам и поиск ставок с перевесом: данные Liquipedia, кэфы OddsPapi, рейтинг и новости HLTV, сводки Claude. Всё работает в облаке: ничего не нужно ставить на компьютер.

## Как это устроено

- **Сбор** (`cs2form/liquipedia.py`, `cs2form/update.py`): каждые 6 часов GitHub Actions через официальный API Liquipedia скачивает турниры тиров S/A/B: каждую карту со счётом по раундам, ближайшие матчи, составы команд на каждом турнире и ссылки на интервью. С HLTV берутся рейтинг команд и лента новостей.
- **Кэфы** (`cs2form/odds.py`): раз в сутки утром через OddsPapi берутся кэфы 150+ контор на ближайшие матчи: победа, форы и тоталы карт, рынки отдельных карт. Прошлые линии для проверок качает `cs2form/history.py` (эндпоинт истории бесплатный).
- **Модель** (`cs2form/model.py`): логистическая регрессия на 15 признаках «до матча». Главные: рейтинг по разнице раундов, рейтинг пятёрки игроков (составы с турниров, поэтому при переходе игрок переносит силу с собой), Elo на конкретной карте, форма текущего состава, личные встречи, опыт офлайна (для матчей на LAN), посев. Проверка на истории — во вкладке «Модель».
- **Вето и матч**: жадная симуляция вето (команды выбивают карты, которые не играют, и самые невыгодные, выбирают самые выгодные), шанс серии считается по картам, которые реально будут сыграны, с общей на серию формой дня (`cs2form/markets.py`).
- **Ставки** (`cs2form/value.py`, `cs2form/scan.py`): шанс для ставки — линия Pinnacle без маржи, ставка — когда кэф другой конторы выше честной цены на 5%. Модель в расчёт не входит: на 402 прошлых матчах она уступила рынку (вкладка «Модель»). Виртуальный банк, которым Claude ставит сам, — `cs2form/bank.py`.
- **Проверки на истории**: `cs2form/vsmarket.py` сравнивает модель с линией Pinnacle, `cs2form/vspinnacle.py` считает, что дали бы ставки по кэфам выше честной цены. Итоги лежат в `data/backtest.json` и показываются в приложении.
- **Новости** (`cs2form/news.py`): для матчей на 3 дня вперёд — новости HLTV и интервью по обеим командам и заметки о составах; при наличии секрета `ANTHROPIC_API_KEY` Claude пишет сводку и ставит флаги риска.
- **Дашборд** (`app.py`, Streamlit): «Ставки», «Матчи дня», рейтинг формы, команда, сравнение, «Модель», журнал.

## Запуск

1. **Сбор данных:** вкладка **Actions** → «Обновить данные» → **Run workflow**. Дальше он запускается сам каждые 6 часов. Поля `days` и `full` перекачивают историю глубже (18 месяцев — около часа).
2. **Кэфы:** секрет `ODDS_API_KEY` (OddsPapi). Прошлые линии: Actions → «Прошлые кэфы Pinnacle», поле `books` добавляет конторы к уже скачанным матчам без новых платных запросов.
3. **Дашборд:** зайти на [share.streamlit.io](https://share.streamlit.io) через GitHub → **Create app** → репозиторий `Cs2-form`, ветка `main`, файл `app.py` → **Deploy**. Получится постоянная ссылка; после каждого обновления данных дашборд подтягивает их сам.

## Что проверено на истории

- Линия Pinnacle предсказывает победителя точнее модели: log loss 0.60 против 0.66, угадано 68% против 59% (402 матча, июнь – октябрь 2026). Любая доля модели в прогнозе делала его хуже, поэтому `value.MODEL_WEIGHT = 0`.
- Ставки по кэфам выше честной цены Pinnacle на 5% (442 матча, шесть контор): +10% итога при разбросе ±21% и +13% к линии закрытия, причём выше линии закрытия оказались 85% ставок. Если считать честную цену по медиане контор вместо Pinnacle, итог −32%, поэтому без линии Pinnacle ставок нет.
- Опыт офлайна помогает: на LAN-матчах у команды с большим числом сыгранных там карт шансы выше, и прогноз по картам стал точнее (log loss 0.6526 → 0.6505 на всех картах и 0.6611 → 0.6565 на матчах с линией Pinnacle).
- Нелинейная модель (бустинг на тех же признаках) и смесь модели с линией Pinnacle в любой пропорции оказались хуже простой логистики и чистой линии.
- Сила по сторонам (CT/T) и перекос карт по сторонам прогноз не улучшили, хотя сам перекос в данных виден: Overpass 57% раундов за CT, Nuke 56%, Mirage 55%.
- Форы и тоталы, выведенные из линии Pinnacle на победу, не хуже собственных линий Pinnacle на эти рынки, так что лесенка рынков в приложении считается от кэфов на победу.
- У 1xBet и Melbet в OddsPapi фора записана для команды своего исхода, а не для участника 1: такие линии приводятся к одной записи (`scan._unflip`), иначе лучший кэф берётся не с той стороны.

## Ограничения

- Статистика и страницы матчей HLTV закрыты Cloudflare от серверов GitHub, поэтому карты берутся с Liquipedia (по правилам их API: свой User-Agent, не чаще запроса в 2 секунды).
- Порядок вето на Liquipedia обычно не записан, поэтому вето предсказывается по карт-пулам, а не учится на реальных вето.
- Модель угадывает около 60% карт — это честный уровень для CS2; используйте её как ориентир, а не как основание для ставки.
- Бесплатный тариф OddsPapi — 250 запросов в месяц, поэтому кэфы берутся раз в сутки утром.
